个税一键申报 — Windows 连接端与完整运行包

配合 Mac 使用：请先看“Mac与Windows连接说明.txt”，在 Windows 双击“启动Mac连接.cmd”并复制连接码，在配套 Mac 应用中粘贴连接。

使用方法
1. 把整个 ZIP 解压到 Windows 电脑上的普通文件夹。不要在压缩包里直接启动。
2. 双击“一键启动.cmd”，打开主程序。随包附有 Python 运行依赖、OCR 模型和 Chromium 浏览器，无需另外安装 Python。
3. 微信与Excel配对或只使用微信截图回执时，双击“微信群与Excel配对.cmd”。首次先创建配对表，操作见“微信与Excel联动说明_1.1.0.txt”。
4. 保留完整目录；runtime 与 runtime-wechat 都需要各自的 _internal 子目录，不要只复制 EXE。

资料与配置
原仓库的 settings.json、data 申报记录、wechat/config.json 均保留。新的浏览器首次使用需要自己登录；原上传没有包含的登录会话无法重建。
请保留 data/state.json，已有申报记录用于防止重复办理。
微信模块继续从 wechat 文件夹读取原有 Python 源码；更新该文件夹后重开微信窗口即可。

实际业务环境
这是 Windows x64 程序，Mac 不能直接运行这些 EXE。
实际办理需要已安装并登录相应税务扣缴客户端，保持 Windows 桌面解锁。微信功能需要兼容的微信客户端与 Windows 简体中文 OCR 能力；wxauto4 41.1.7 官方兼容说明对应微信 4.1.8.107。
首次请按“使用说明.md”进行现场核对。准备并检查会生成草稿；“一键申报”和原有“测试”业务按钮可能真正提交，不能用来检查软件是否安装好。

打包验证范围
构建流程执行离线单元测试，并在独立临时目录、移除系统 Python 搜索路径后运行两套 EXE 的 --self-test。
主自检检查 Tk 窗口、Windows 自动化依赖、OCR 模型和随包浏览器的离线页面；微信自检检查运行依赖、完整配对窗口、临时Excel创建写入读取和模块导入。
这些检查不访问税务业务网站、不提交申报、不发送微信。原仓库说明中的真实界面与完整申报链路仍需要现场联调。
具体构建平台、依赖版本和自检结果见 build-reports 与 build-info.json。

重新构建
源代码及 build.ps1 已附带；重新构建需要 Windows Python 3.12 x64 和下载依赖的网络连接。便携包日常使用不需要这些构建工具。
