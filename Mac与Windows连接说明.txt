个税一键申报 — Mac 操作与 Windows 执行

配对使用
1. 将 Windows 连接端 ZIP 完整解压到 Windows 的普通文件夹。不要在压缩包内直接运行，也不要只复制 EXE。
2. 双击“启动Mac连接.cmd”，保持连接窗口打开，点击“复制连接码”。首次若 Windows 弹出网络访问提示，允许自己的专用网络。
3. 在 Mac 上安装并打开配套“个税一键申报 Mac.app”，粘贴完整连接码，点击连接。两台电脑需在同一局域网。
4. 在 Mac 上先读取网页名单、检查扣缴端并核对月份。带“实际提交/实际申报”的操作会弹出确认，再交给 Windows 执行。
5. Windows 必须开机、已登录并保持桌面解锁；任务运行时不要休眠、切换用户或操作扣缴客户端。Mac 关闭不会自动停止 Windows 正在执行的任务，需要停止时先用界面的停止按钮。

已有 Windows 运行目录的更新
如果原目录里已有最新申报记录和配置，请先备份整个原目录。将本包的 runtime、runtime-wechat 文件夹，以及 app.py、bridge_host.py、bridge_protocol.py、启动Mac连接.cmd 复制到原目录，替换对应运行组件；继续从原目录启动。
不要用压缩包里的 data、settings.json 或 wechat/config.json 覆盖自己更新过的资料。data/state.json 是原程序判断已办记录的依据，必须保留。连接信息与远程任务记录自动保存到 Windows 当前运行目录 data/mac_bridge。
首次使用、尚无更新记录时，直接在本包解压目录运行即可；原仓库上传的配置和数据已按 Git 原始字节保留。

Windows 单独使用
双击“一键启动.cmd”打开原主程序；只用微信截图回执时，双击 wechat 文件夹里的“微信截图回执.bat”。随包附有 Python 运行依赖、OCR 模型、Chromium 浏览器和加密连接组件，无需另外安装 Python。
保持 runtime、runtime-wechat 及各自 _internal 子目录完整。不要同时通过 Mac 和 Windows 主窗口启动业务任务。

首次运行与业务条件
在 Windows 上安装并登录实际使用的税务扣缴客户端；网页工作台首次使用需要登录，原上传未包含的登录会话无法重建。微信流程沿用原仓库的 Windows 微信配置。
连接码包含配对密钥，只给自己的 Mac 使用。本连接端只接受私有局域网 IPv4 / 本机地址，采用 HTTPS 和连接码中的证书指纹校验，无需安装系统证书。
准备并检查会生成草稿；“一键申报”和原有“测试公司/测试部分 0”按钮会真正提交，不能用来检查安装是否成功。
断线后请重新连接查看同一任务。程序不会自动重发申报；如果 Windows 意外退出，先核对扣缴端与已有记录再决定后续操作。

验证范围
构建流程在实际 Windows x64 环境运行原单元测试与新增连接测试，再把 EXE 复制到含中文、空格的临时路径，移除外部 Python 搜索路径后运行离线自检。
主自检检查 Tk 窗口、Windows 自动化依赖、OCR 模型和随包浏览器；微信自检检查依赖与 Tk；连接自检检查冻结程序内的加密组件、窗口、局域网协议及任务去重流程。
上述检查不访问税务业务网站、不提交申报、不发送微信。真实扣缴界面与企业申报链路仍需按“使用说明.md”完成现场核对。
构建来源、依赖版本和自检结果见 build-info.json 与 build-reports。
